# Ясный нейтральный русский

Самодостаточный навык Codex для точных и понятных текстов на русском языке: объяснений разработки, документации, задач, описаний изменений, интерфейсных сообщений и обычной переписки.

Навык помогает убрать канцелярит, неоднозначность и повторения. Сохраняет факты, условия, ограничения и степень уверенности. Не требует внешнего руководства или словаря.

## Установка

Попросите Codex:

```text
$skill-installer Установи навык simplified-russian из репозитория decyrus/simplified-russian, путь skills/simplified-russian.
```

## Использование

```text
$simplified-russian Объясни, почему этот запрос возвращает ошибку.
```

```text
$simplified-russian Перепиши описание изменений: …
```

```text
$simplified-russian Сделай сообщение ясным и нейтральным: …
```

```text
$simplified-russian Проверь требования на неоднозначность: …
```

Имя вызова сохранено: `$simplified-russian`.

## Примеры

| До | После |
| --- | --- |
| Была произведена реализация механизма повторного выполнения запросов. | Добавлены повторные запросы. |
| Ошибка осуществления сохранения. | Не удалось сохранить изменения. |
| Просьба осуществить направление замечаний до пятницы. | Пришлите замечания до пятницы. |

## Границы

Навык управляет языком и подачей текста. Он не меняет архитектуру, логику программы или технические требования ради стиля. Предположение остается предположением, а неизвестные сведения требуют уточнения.

При явном вызове стиль применяется к ответам по текущей задаче. Автоматический выбор предусмотрен для запросов на простой, точный, нейтральный или контролируемый русский.
