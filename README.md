# Навык: Упрощенный русский язык

Это навык лаконичного технического русского языка для ИИ-помощников для разработки, документации и обычного общения.
Нечто вроде ASD-STE100, ГОСТ Р 58049-2017, которые используются в инженерии для избежания ситуаций неоднозначности и избыточности речи.

## Почему я сделал этот навык

Я вдохновился [твитом Андрея Карпаты про ASD-STE100](https://x.com/karpathy/status/2105819303471976479) и захотел сделать аналог на русском языке. По моему мнению, структура и простота текста важны для разработки: они помогают точнее формулировать задачи, объяснять решения и понимать друг друга. Четкое понимание перевода термина на русский дает больше ясности.

## Установка и подключение

Правила написаны в обычном Markdown и не требуют API или сервера. Способ установки зависит от приложения. Команды в блоках `text` ниже нужно отправлять сообщением ИИ-помощнику, а не выполнять в терминале.

### Codex

Отправьте в Codex:

```text
$skill-installer Установи навык simplified-russian из репозитория decyrus/simplified-russian, путь skills/simplified-russian.
```

Вызов после установки:

```text
$simplified-russian Перепиши этот текст в строгом режиме: …
```

### Claude Code

Отправьте в Claude Code:

```text
Установи навык из https://github.com/decyrus/simplified-russian.
Скопируй каталог skills/simplified-russian вместе со всеми вложенными файлами
в ~/.claude/skills/simplified-russian.
Если навык уже установлен, сначала покажи различия.
```

Для установки только в текущем проекте укажите `.claude/skills/simplified-russian` внутри проекта вместо `~/.claude/skills/simplified-russian`.

Вызов после установки:

```text
/simplified-russian Перепиши этот текст в строгом режиме: …
```

### Claude с загрузкой навыков

Если в вашем интерфейсе Claude доступна загрузка пользовательских навыков, создайте ZIP с папкой `simplified-russian` из каталога `skills` и загрузите его в разделе Skills. Архив должен содержать эту папку с `SKILL.md` и `references`, а не весь репозиторий. Включите навык после загрузки.

### Другие ИИ-помощники с доступом к файлам и GitHub

Отправьте помощнику:

```text
Установи навык simplified-russian из репозитория
https://github.com/decyrus/simplified-russian.

Навык находится в skills/simplified-russian.
Определи поддерживаемый тобой способ установки и сохрани все вложенные файлы.
Если навык уже установлен, сначала покажи различия.
Если установка навыков недоступна, объясни, как использовать эти инструкции
в твоей среде. Не сообщай об успешной установке, если она не выполнена.
```

Это запрос помощнику, а не единая команда установки для всех приложений. Поддержка навыков, место установки и синтаксис вызова зависят от среды. Работа во всех приложениях не проверена.

### Обычный чат без установки навыков

Прикрепите `skills/simplified-russian/SKILL.md`. Для работы с терминологией также прикрепите `references/lexicon.md`, а для проверки поведения — `references/examples.md` из той же папки навыка.

Затем отправьте:

```text
Используй приложенные правила simplified-russian при написании
и редактировании русских текстов в этом чате.
Выбирай режим по типу текста, если я не указал его явно.
```

Если чат не поддерживает вложения, вставьте содержимое нужных файлов в сообщение. Одна ссылка на репозиторий не гарантирует, что помощник прочитает инструкции и справочники. В новом чате может потребоваться передать их повторно.

### Какие файлы нужны

При установке переносите папку `skills/simplified-russian` целиком, сохраняя структуру `references`. Файл `agents/openai.yaml` содержит необязательные метаданные для интерфейса OpenAI; другим средам он не нужен для применения правил.

После подключения попросите помощника переписать короткую инструкцию и проверьте результат. Наличие файлов само по себе не подтверждает, что помощник загрузил навык.

## Использование

```text
Примени simplified-russian. Перепиши требования в строгом режиме: …
```

```text
Примени simplified-russian. Проверь инструкцию и покажи замечания с кодами правил: …
```

```text
Примени simplified-russian. Сделай сообщение ясным и нейтральным: …
```

В Codex используйте `$simplified-russian`, в Claude Code — `/simplified-russian`. В обычном чате примеры работают после передачи инструкций в контекст.

## Режимы

| Режим | Когда применяется | Правила формы |
| --- | --- | --- |
| Строгий | Требования, процедуры, инструкции, техническая документация | До 25 слов в предложении, одно самостоятельное действие в шаге, явные условия |
| Нейтральный | Объяснения, переписка, обычные ответы | Естественная речь без числового ограничения длины |

Явный выбор важнее автоматического. В смешанном документе режим выбирается для каждого фрагмента.

В обоих режимах сохраняются факты, отрицания, условия, ограничения, последовательность, одновременность и степень уверенности. Код и точные названия не меняются ради стиля. Структурные исключения допустимы ради смысла и объясняются при аудите.

## Правила технического текста

В строгий режим добавлены правила, адаптированные из раздела 8 ГОСТ Р 58049-2017: ясные связи в цепочках существительных, упрощение причастных и деепричастных оборотов, одна тема в абзаце, условия в начале предупреждения и последовательные сокращения.

Это выборочная адаптация для разработки и общения, а не реализация стандарта целиком. Лимит 25 слов и подсчет по пробельным символам остаются собственными правилами навыка. Рекомендация ГОСТа о 20 словах с отдельными допущениями подсчета не перенесена. Нейтральный режим сохраняет естественную речь без числового ограничения.

## Словарь

Словарь задает рабочие значения 20 терминов разработки и различия между близкими понятиями. Терминология проекта имеет приоритет. В каждой статье указаны допустимое сокращение и нежелательная замена. Сокращения базовых терминов не заданы; варианты могут быть определены проектом. Слова вне словаря разрешены; словарь контролирует значения, а не закрывает лексику.

## Результат проверки

При редактуре навык выдает готовый текст. При аудите — фрагмент, код правила, категорию, проблему и правку. Он различает смысловые ошибки, структурные нарушения и допустимые исключения. Стилистические советы отмечаются как рекомендации.

Программного проверяющего инструмента в этой версии нет. Проверка моделью не является точной программной валидацией или подтверждением соответствия внешнему стандарту.
