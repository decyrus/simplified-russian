# Контролируемый технический русский

Навык Codex для написания, редактирования и проверки технических текстов по принципам упрощенного технического русского (УТР / Simplified Technical Russian).

Помогает сделать инструкции однозначными: использует последовательную терминологию, прямой порядок слов и ясные команды. Сохраняет технические факты, числа, условия, ограничения и последовательность действий.

## Установка в Codex

Отправьте в Codex:

```text
$skill-installer Установи навык из https://github.com/decyrus/simplified-russian/tree/main/skills/simplified-russian
```

## Использование

```text
$simplified-russian Перепиши эту инструкцию на контролируемом техническом русском: …
```

```text
$simplified-russian Проверь руководство. Покажи неоднозначные фрагменты и предложи исправления: …
```

Можно передать словарь проекта вместе с текстом. Без словаря навык выбирает последовательные термины в пределах документа, но не объявляет их утвержденной отраслевой нормой.

## Пример

До:

> Осмотр фильтра осуществлять не реже одного раза в неделю.

После:

> Осматривайте фильтр не реже одного раза в неделю.

## Основа и ограничения

Навык создан на основе презентации Антона Тарасенко, АВИАОК Интернейшенел, [«Упрощенный Технический Русский: принципы, преимущества, пути реализации»](https://www.s1000d.ru/userforum/presentations/Day_3_Track1_04_Simplified_Russian.pdf).

Презентация описывает принципы, но не содержит полного нормативного руководства и словаря УТР. Навык не подтверждает соответствие стандарту и не является официальным продуктом авторов презентации. Для проверки по конкретным нормативным требованиям предоставьте применимое руководство и утвержденный словарь.

PDF не включен в репозиторий. В справочнике приведены ссылки на страницы источника и собственные примеры применения.
